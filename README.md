# Tic Tac Toe

This is a static website exported from Code.org App Lab. The deployable files are extracted into `public/`, including `index.html`, the application code, styles, and App Lab assets.

Netlify uses `netlify.toml` to publish `public/`. No build command or dependency installation is required.

To update the app, export it from App Lab and replace the contents of `public/` with the files inside the exported app folder. Keep `index.html` directly inside `public/`, rather than uploading only the ZIP file or nesting another folder inside `public/`.

The original ZIP is kept as a source backup. The exported app also loads external scripts from Code.org, jQuery, and Google, so it requires an internet connection.
